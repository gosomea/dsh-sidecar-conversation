# 插件内会话层级与添加到主会话

本轮只修改插件。DSH checkout 为官方 `22ddee3792` / `0.2.1-rc.3`，源码工作区无修改。所有旧会话及侧问索引保留。

## 行为

- 默认显示插件会话层级：关联 Fork 嵌套在可见父会话下，独立会话保持顶层。父会话不可见时子会话仍可访问；损坏的循环关系不导致递归或隐藏会话。
- 标题、置顶、归档、打开和重命名使用原生 Session 数据/服务；顺序只读原生工作区 store。折叠状态保存为浏览器偏好。
- “管理”与底部“原生列表”切回 DSH 完整工作区管理、全文搜索、拖动排序；“会话层级”返回。层级视图提供标题筛选，不宣称实现原生列表的全部交互。
- 选区菜单末尾新增“添加到主会话”。插入来源主 Session 的原生输入框，保留原有文本和引用，不创建侧问、不切换右侧标签。主 Session 在异步期间已切换时拒绝插入。
- 新引用沿用原生草稿、用户消息 codec 和点击定位。选文高亮选区，回合引用高亮回合。
