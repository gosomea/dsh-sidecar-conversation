# 统一左侧会话列表验证

本记录对应 0.2.6 的统一左侧列表。发布前，日常 3080 已安装经过隔离验证的同一功能构建；0.2.6 仅继续整理版本信息与文档。

## 行为与原生边界

- `sidebar.workspaces` 只显示一个插件列表，移除“管理 / 原生列表 / 会话层级”切换。
- 会话摘要、工作区成员、置顶和归档状态继续取自原生服务。搜索调用原生 `searchSessions`，包括取消过期查询；默认关闭全文索引的 DSH 只匹配标题及工作区名称，不显示错误提示。原生索引启用时合并正文结果并显示片段。
- 拖动只调整同工作区、同父节点、同置顶区块的会话，写入原生 `setSessionOrder`；不更改侧问父子关系。保留隐藏、归档及摘要尚未到达的成员，避免刷新过程中丢序或崩溃。首次拖动从最近更新切换为原生手动排序。
- 分组、排序、归档筛选和工作区展开状态复用原生视图 store。侧问折叠仅是插件本地视图偏好。独立会话仍为根节点。
- 置顶、取消置顶、归档、取消归档调用 `uiWorkspace` 原生操作；重命名仍调用原生对话框。未修改 DSH 源码、会话日志或侧问索引格式。

## 验证

- Node 24：`pnpm check`、`pnpm test`（24 文件、190 测试）、`pnpm pack` 通过。检查包内入口、声明及 patch 均存在，无测试 home 或秘密文件。
- 新增测试：全文搜索取消与过期响应隔离、搜索失败标题降级、原生索引禁用、同级拖动、禁止跨父节点/置顶区块移动、隐藏成员保留、归档筛选及点击保护、刷新摘要未到达时的顺序处理。原有折叠持久化与插槽稳定性测试继续通过。
- 3187 使用独立 DSH_HOME、官方 rc.3 干净源码运行，安装实际 tgz。通过 UI 验证原生置顶/取消、归档/恢复、筛选、折叠刷新、侧问拖动及刷新顺序。
- 原生索引默认禁用路径实测后，仅在隔离 patch 配置 `session-query-sqlite: { path: ':memory:', openAt: first-search }`。正文 `MAIN-REFERENCE-OK` 正例命中父会话，随机不存在查询返回空结果。日常索引配置未变。
- 存储独立核对：隔离 registry 中该父会话 7 个关联侧问与树显示一致；归档操作写入原生 `storages/workspace.json`，恢复后归档集合回到空。
- 浏览器实测发现并修复了手动排序重载时摘要尚未到达导致列表崩溃的问题；最终包重新加载、全文搜索和刷新通过。
- 发布提交由 GitHub Actions 执行 Windows/Linux 的类型检查、自动测试、构建与打包；浏览器实测在 macOS 进行，不作为 Windows 浏览器实测声明。
