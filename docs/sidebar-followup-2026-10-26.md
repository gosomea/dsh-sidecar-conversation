# 0.2.7：左侧列表修复与图标对齐

基于 0.2.6，仅修改插件；DSH rc.3 源码未改动。

## 问题与处理

- 原生新会话可以复用已有空 Session，其保存的标题可能是“新侧问”。原生行根据 `summary.blank` 显示“新会话”，统一列表漏掉这一规则。现已对齐显示规则，空会话也不提供重命名和归档菜单；不改写 Session 标题和日志。
- 工作区标题旁补充新建按钮，调用原生注入的 `startSession(workspaceId)`，同时展开该组。无会话的工作区也保留入口。折叠、搜索、排序和归档筛选继续使用已有实现和原生状态。
- 工作区标题增加文件夹图标、统一间距；三个筛选框收起至“列表显示选项”。这不是原生 UI 的完整复刻。
- 底部恢复双向列表切换，浏览器保存偏好。切换解除/重建公开 `sidebar.workspaces` 插槽覆盖，不移动 DOM，不导入 DSH 私有模块。原生列表的添加工作区、重命名/移除、插件行扩展等完整功能仍由原生提供。

## 验证

- 已注册隔离环境 `sidecar-stock-alpha3-20261024`，3187，官方未修改 DSH rc.3；安装本次打包产物，通过浏览器工作区“＋”和全局新建确认行显示“新会话”，工作区选择正确。
