# Phases

## Phase 1 — release blockers (complete)

- Explicit access mode.
- Loopback browser trust fence and JSON media-type boundary.
- Draft-scoped UUID create identity plus server payload consistency checks.
- Transcript pagination through the first prompt.
- Unit and integration-shaped regression tests.

## Phase 2 — lifecycle and scale (complete)

- Archive/restore UI and retention policy.
- Inactive-layout observer removal.
- Registry transaction serialization.
- The native Surface is the only transcript path; the plugin owns no transcript EventSource or renderer.

## Phase 3 — native conversation convergence (transcript complete)

- Harness exposes an arbitrary-Session Conversation Surface and detached open path.
- Sidecar consumes the shared transcript and keeps Sidecar-only source, permission, composer, and interaction chrome.
- Older Harness versions fail closed with a compatibility error instead of silently switching to a divergent renderer.
