# 0.2.0

此版本包含原生侧栏聊天、独立会话与 Fork、结构化引用和来源跳转，以及原生标题和顺序同步。npm 使用默认 `latest` 通道；GitHub 使用 `v0.2.0` 正式 Release。

## 安装前提

目标 DSH 必须是 `0.2.1-alpha.3` API 基线，并包含本地 ui-workspace 的两项扩展：

- `uiWorkspace.sessionOrder`：发布原生会话顺序。
- `sidebar.workspaces.session.title`：允许侧问装饰会话标题。

这些 DSH core 扩展不包含在插件 npm 包中。普通 npm DSH `0.2.1-alpha.3` 本身不能满足要求，缺少排序接口时会明确报错。原生左栏的父子折叠也由目标 DSH 提供。安装前应先确认目标 DSH 具有这两项能力。
