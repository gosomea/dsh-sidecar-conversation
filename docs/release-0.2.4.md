# 0.2.4

选文浮层和「侧问这个回合」菜单统一按以下顺序显示：

1. 追加到最近侧问：仅在当前主会话存在可用侧问目标时显示，保持第一位。
2. 从此回合 Fork。
3. 仅用选文新建／仅用此回合新建。

没有可用侧问时，仅显示 Fork、独立新建两个选项。菜单调整不改变各按钮的目标会话、来源引用、权限或创建方式；不修改 DSH 源码、Session log、registry v3 或现有会话。

## 验证

- `selection-menu.test.tsx` 与 `turn-menu.test.tsx` 共 9 项通过，类型检查通过。用例覆盖有／无目标时的顺序、追加仍指向最近目标、Fork 仍携带本次来源，以及独立新建仍使用当前选文或回合。
- 官方 npm DSH `0.2.1-alpha.3` 的隔离环境 3187：真实浏览器打开选区浮层和回合菜单，均显示「追加 → Fork → 独立新建」。复用既有测试会话，不需要新增模型请求。
- 日常 3080 的客户端菜单调整已验证；进程 PID 保持不变，727 个会话与 36 条侧问记录保留，749 个会话文件、侧问索引和 Host 产物未变化。此处为菜单调整部署时的核对记录，发布流程不再次重启日常实例。
